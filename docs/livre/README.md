# Comprendre la comptabilité générale suisse

Un livre d'apprentissage, construit au fil du projet. Il explique les notions de la comptabilité générale telle que la pratique un ERP suisse comme Abacus, à travers une seule entité fictive : le Cabinet médical des Tilleuls Sàrl.

## Mode d'emploi

- Les chapitres suivent l'ordre d'apprentissage. Chacun s'appuie sur les précédents.
- Tous les exemples utilisent le scénario chiffré du [chapitre 00](00-le-cabinet-des-tilleuls.md). Les tests du code retrouvent les mêmes chiffres.
- Chaque chapitre suit le même gabarit :
  1. Définition
  2. À quoi ça sert
  3. Exemple
  4. Pièges et cas subtils
  5. Loi suisse et pratique Abacus
  6. Dans le code
  7. Questions fréquentes
- La section « Loi suisse et pratique Abacus » distingue ce qui relève de la loi (CO, Olico, LTVA) et ce qui relève de la pratique d'Abacus. Les points incertains y sont signalés comme tels.
- Le [glossaire](../glossaire.md) donne une définition courte de chaque terme.
